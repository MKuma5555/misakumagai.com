# public フォルダ

ここに置いたファイルは、そのままのパスで配られる。
`public/foo.png` → `https://www.misakumagai.com/foo.png`

## 消してはいけないファイル

### googlec5b98d83555c4a9c.html

Search Console の所有権確認に使っている。
中身は1行だけで、意味があるのはファイル名のほう。

消すと所有権が外れ、検索の状況が見られなくなる。
確認が済んだあとも置いておくこと。

なぜファイル方式かというと、`/` は中身を持たないため。
`/` は proxy.ts が `/ja` か `/en` に振り分けるだけなので、
Google が見に来ても HTML が無く、タグやGAのコードで確認できない。
拡張子付きのURLは proxy.ts が触らないので、このファイルは直接届く。
